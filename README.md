# ✅ Task Manager

A modern task management web application built using **HTML**, **CSS**, and **JavaScript**.

This project was created as part of my software engineering portfolio to demonstrate front-end development, DOM manipulation, Local Storage, and responsive web design.

---

## 🚀 Features

- ➕ Add new tasks
- ⌨️ Press Enter to quickly add tasks
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🗑️ Clear all tasks
- 💾 Automatically saves tasks using Local Storage
- 📅 Optional due dates
- 🔍 Search tasks instantly
- 📂 Filter by:
  - All Tasks
  - Active Tasks
  - Completed Tasks
- 📊 Live task counter
- 🌙 Dark Mode
- 🎨 Multiple colour themes
- 📱 Responsive mobile-friendly design

---

## 🛠 Technologies Used

- JavaScript (ES6)
